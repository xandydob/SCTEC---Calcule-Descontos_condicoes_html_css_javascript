📦 Calculadora de Descontos - Projeto Lab365/SCTec
Esta é uma aplicação web simples e moderna desenvolvida para calcular descontos em produtos de forma automática. O projeto foi criado como parte da trilha de desenvolvimento de software, focando na manipulação do DOM e lógica de programação com JavaScript.

🚀 Funcionalidades
Cálculo Automático: Aplica descontos baseados no valor inserido ou categoria do produto.

Lógica Condicional: Utiliza estruturas if/else para determinar a porcentagem de desconto.

Interface Responsiva: Layout adaptável para dispositivos móveis e desktops.

Feedback Visual: Exibe o valor original, o valor do desconto e o total final.

🛠️ Tecnologias Utilizadas
HTML5: Estruturação semântica da página.

CSS3: Estilização moderna com foco em UX (User Experience).

JavaScript: Lógica de cálculo e manipulação dinâmica dos elementos da página.
